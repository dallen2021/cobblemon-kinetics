# Support

Create: Cobblemon Kinetics is a volunteer, pre-release project. Support is
best-effort; there is no guaranteed response time, and maintainers may close
requests that cannot be reproduced on the supported dependency set.

## Before asking for help

1. Read the README's installation, compatibility, configuration, and playtest
   sections.
2. Confirm that Java, Minecraft, NeoForge, Create, Cobblemon, Kotlin for Forge,
   and this mod match the versions pinned by the repository or release notes.
3. Remove unrelated mods and datapacks when practical, then try a new world.
4. Search open and closed issues for the same symptom.
5. Keep `latest.log` and the matching crash report. Use `debug.log` only when it
   contains information needed to diagnose the problem.

Redact tokens, private server addresses, filesystem usernames, player
identifiers, and unrelated personal information before sharing logs.

## Where to ask

- Use the **bug report** issue form for reproducible crashes, incorrect
  behavior, save/load problems, and multiplayer desynchronization.
- Use the **feature request** form for focused gameplay, configuration,
  accessibility, API, or tooling proposals.
- Use the **Create add-on compatibility proposal** form for researched optional
  integrations.
- Use pull requests for finished, scoped changes that follow
  [CONTRIBUTING.md](CONTRIBUTING.md).

Please do not use unrelated upstream trackers to report this mod's bugs. If a
problem reproduces without Create: Cobblemon Kinetics, report it to the project
that owns the affected code and follow that project's support requirements.

## Supported scope

The supported environment is the exact version set documented in the README
and the latest tagged release notes. Snapshots, modified jars, forks, arbitrary
modpacks, newer generations, Fabric, and unlisted Create add-ons may be useful
for diagnosis but are not guaranteed support targets.

Maintainers may ask for a minimal reproduction, complete version list, clean
log, test world, or confirmation on the pinned versions. A modpack export or a
link to a legally redistributable reproduction pack is preferable to a folder
of uploaded third-party jars.

## Security and conduct

Do not disclose suspected vulnerabilities in a public support request. Follow
[SECURITY.md](SECURITY.md) instead. Harassment, private-information exposure,
and other community concerns are handled under
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
