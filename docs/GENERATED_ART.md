# Generated interface art

The website's first visual set was generated on 2026-08-14 with OpenAI's built-in image-generation tool. The source images are original project illustrations: no Create, Minecraft, Cobblemon, Pokémon, PokéAPI, or add-on image was supplied as a visual reference or extracted into the repository.

The shared direction is an original fantasy-industrial workshop rendered as polished painterly 3D art: aged brass, copper, oxidized-teal enamel, dark steel, cream ceramic, cyan water, and warm upper-left light. Creature and machine silhouettes were explicitly prompted not to reproduce an existing game character, block, machine, texture, or logo.

The transparent assets were generated against a flat chroma background, converted to alpha with the repository-independent ImageGen helper, and encoded as WebP for the website. The app icon is a resized PNG derivative of the emblem.

## Usage boundary

The Water Worker is a generic original role symbol. It must not be labeled or distributed as Squirtle or any other Pokémon species art. New generated artwork should preserve the same no-reference rule unless an exact third-party asset has separately passed the repository's source, license, attribution, and visibility review.
